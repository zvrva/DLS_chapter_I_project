# Проект: Сегментация спутниковых снимков и вычисление площади застройки

## Быстрый старт
1. Установите зависимости для запуска приложения
```bash
pip install requirements.txt
```
2. Скачайте модели сегментации зданий и детекции машин. Распакуйте файлы в корень проекта
```text
https://drive.google.com/file/d/1P4y5eNIFKDT3YBS6iPy0fz6Zgorc1HTW/view?usp=drive_link
```
3. Запустите приложение
```bash
streamlit run app.py
```
4. По желанию установите зависимости для запуска ноутбуков
```bash
pip install requirements-notebooks.txt
```

## Структура
- `app.py` — основное приложение
- `models/` — архитектура модели сегментации
- `utils/` — обработка изображений, визуализация, детекция машин
- `best_model_v3.pth` — лучшая модель сегментации
- `best_cars_detection_v1.pt` — лучшая модель детектции машин
- `example.tif` — пример входного снимка
- `Segmentation.ipynb`, `Cars_Detection.ipynb` — исследовательские ноутбуки
- `test_preds.zip` — полученные сегментированные изображения для тестовой выборки


## Примечания
- Для сегметанции зданий есть настройки порога уверенности модели (от 0.1 до 0.9) и прозрачности наложения маски (от 0.1 до 0.9)
- Для детекции машин есть настройки порога уверенности модели (от 0.1 до 0.95) и количества машин для усреднения (1, 10, 25)
- Для оценки площади используется детекция машин и средняя площадь найденных авто в пикселях (при условии, что средння площадь авто 8 м²)
